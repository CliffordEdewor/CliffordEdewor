### 🧭 About Me

**Cybersecurity Specialist** focused on IT/OT security operations, critical infrastructure protection, incident response, vulnerability management, and cyber resilience across regulated and safety-critical environments.

Recognised nationally as the **CSEAN Rising Star of the Year 2026** (Cybersecurity Merit Awards) for emerging leadership in cybersecurity, critical infrastructure protection, and cybersecurity workforce development.

As an **IT/OT Security Operations Officer at Sinic Engineering Limited (SROL)**, my work focuses on industrial cybersecurity, security monitoring, incident response support, vulnerability management, access controls, and cybersecurity awareness across enterprise and operational technology environments.

My experience spans **industrial cybersecurity, election cybersecurity, detection engineering, cloud security, and Agentic AI security**, including designing and securing agentic AI workflows using Amazon Bedrock AgentCore, AWS Cognito, and the Model Context Protocol (MCP).

I have trained and mentored **500+ learners** in cybersecurity, network security, secure coding, and computer networking through educational institutions and national workforce-development initiatives, including the **NITDA 3 Million Technical Talent (3MTT) Programme**, **PTI** and **Global Maritime Academy.**

I am committed to strengthening **critical infrastructure security**, advancing the secure adoption of emerging technologies, and developing the next generation of cybersecurity talent.

### 🚀 Featured Projects

### 🔹 [Agentic AI Security at Scale with Strands Agents & Bedrock AgentCore](https://github.com/CliffordEdewor/agentic-ai-security-bedrock-strands)
Production-oriented Agentic AI security reference architecture using AWS Cognito, MCP Gateway, Strands Agents and Amazon Bedrock AgentCore, demonstrating secure design, deployment and observability.

### 🔹 [Secure MCP Agent Integration for AI Tooling](https://github.com/CliffordEdewor/secure-mcp-agent-integration)
Secure agent-tool integration using the Model Context Protocol (MCP) with deployment on AWS AgentCore, demonstrating controlled tool invocation and secure interaction patterns for agentic AI systems.

### 🔹 [Snort IDS Threat Detection](https://github.com/CliffordEdewor/Snort-IDS-Threat-Detection)
Engineered and validated a Snort IDS solution for real-time threat detection, custom rule development, security monitoring, and alert generation within a virtualised enterprise-style network environment.

### 🔹 [IoT Security: Mitigating Cybersecurity Threats in Connected Devices](https://github.com/CliffordEdewor/IoT-Security-Mitigating-Cybersecurity-Threats-in-Connected-Devices)
Security architecture and layered defence strategies for protecting Internet of Things (IoT) environments through practical security design principles.

### 🔹 [Online Voting System](https://github.com/CliffordEdewor/Online-Voting-System)
Secure web-based voting platform demonstrating authentication, election integrity, secure vote casting, and trusted digital voting workflows.

### 🔹 [Network Traffic Security Analysis](https://github.com/CliffordEdewor/Network-traffic-security-analysis)
A Cisco Packet Tracer project demonstrating how hubs broadcast all traffic and how switches intelligently forward frames to improve security and prevent sniffing.
